# 按需域检查（v0.6，非自动物理验证）

只加载当前任务相关项；首轮仍先交低成本整体 3D，记录只需本轮可证的关系。字段、几何端点、功能、时序、接触、输运路径分层报告：几何位置/接触不等于物理连通。

| 域 | 手动锁定的判别点 | 当前工具能做 / 不能做 |
|---|---|---|
| 光学 | 真正作用面、入/出射与转折原因；轴线与束宽/包络分别画 | 已有 `blender_core.py` 针对特定直束做中轴/裁剪基础辅助；新审核仅支持结构简单的双端直圆柱或曲线端点，**不自动验证**反射定律/透镜/焦点/折转原因 |
| 管线/液路 | 每段两端、介质、端口所属主体、最后可辨遮挡，未知回路不闭合 | 静态工具拒绝错端口/介质；保存场景测可见端点相对锚点，**不**判断内部管道、泵向/流量/密封 |
| 电子/RF | 接头数量按来源可辨程度，介质与信号、场区分；实导线不等于 RF 场或逻辑关联 | 记录中 `electric/rf` 与 `field/logical` 分开；无电路导通、阻抗/场求解 |
| 机械 | 支撑面、两端固定关系、单个选定机构状态，弹簧贴近≠力学接合 | 顶点到三角面最近距离作有限近接核查；不证受力、真实接头、碰撞/稳定态 |
| 薄片/层叠 | 上下层序、孔口/真实孔腔、材料类别及可见边缘 | 网格对象存在、渲染状态与几何端点可以核查；不证材料实际透射/内部形貌 |

时序关系应记录 `kind: temporal` 与当前 `operating_state`，不能把多状态设备复制成同时存在的硬件。字段或逻辑关系不得画成实管，图中叠加标签/箭头不是组件。若身份或 owner 变更，依 `dependent_records` 重新查路径、标签、支持、投影和外部 PNG；此前 PASS 不自动继承。表中判别点均为通用检查，不以旧案例作为安装依赖；Skill 文件夹单独复制后本页、合成 fixtures 与 scripts 可用。
