# 通用工作清单（v1.1 门槛；其余按任务选用）｜不设固定视角或采样数

参见 [身份与端口门槛](identity_port_gate_v11.md)、[实物与接口方法](physical_equipment_and_interfaces.md)及 [按需域检查](domain_checks.md)；每项只对**当前用户目标和可获得证据**成立。需要机器核查时使用 [可选项目记录](project_record.md)，不把它变成普通预览的必填大表。主要产物是实物三维示意场景和参考图可对照的低成本预览，不把标签副本或二维草图设为必经步骤。

## 0｜理解来源（P11、P15）
- [ ] 确定用户指定图版/子图、图注、相关正文/方法；记录“已实现／拟建／未定”。批次拼图先核子图范围：裁出装置而不混数据图，保留图号和必要标签；裁图本身也需实际读图复核。
- [ ] **建模前**由源图、图注、用户范围建立 required 装置/外形/可见关系清单，不能从建完的对象反推必需范围或拿通用方块替换关键装置；用标签、轮廓及连续路径交叉核对。建立器件/传输路径/作用面清单：逐件区分 `原图可见 / 正文依据 / 建模假设 / 未定`；图注与正文命名差异并列，不消解。材料类别/名称先查正文和方法，照片外观纹理另列为估计。
- [ ] 在身份有争议时才做标注副本或 2D 草图，并用图中标签、正文、必要型号来源交叉核对。图上红色光束、Hologram/Phase 插图等先判断是否示意，不凭常见结构补实体。

## 1｜最快低成本整体 3D（P1、P16、P17）
- [ ] 先搭正确子图的**整套装配范围**、朝向、层次、相对比例和主要接口；选低成本总览尽早外部读图。照片上的箭头/标框先分离，未证实的硬件不补画。相机/采样按任务设置，不把二维图片 y 当实际高度。
- [ ] 直通段共用光轴；镜面折转按来源与实际面法向；中心线与扩束/准直/聚焦包络分开。源、光纤、探测接口取真实面；避免“中心共线但源端埋在壳体内”。
- [ ] 先对照整体轮廓、连续结构、相对比例与材料类别；功能性孔腔/入口用实几何，不以表面暗点代替。柔性分段按可见轮廓而非方块/纹理噪声；圆片/环面与图形标记各自核身份。已知型号先查公开资料；未知型号和连接器只作代表性假设，不冒充厂家 CAD。笔记本屏/底座/铰链及数据口、示波器/电源/泵/相机的类别控制面应按来源与审图需求区分，不套通用仪器块或旧案例参数。

## 2｜有界的独立核查（P2–P5、P8–P10、P18–P19）
- [ ] 独立载入**已保存** .blend；用实际评估后网格/世界变换核接口 owner 表面、所支持的曲线/直束端点与有限接触（显式场景单位、容差）。锚点从 owner 局部到世界只变换一次；QA 锚点在实作用面（可作不渲染几何证据）；现有工具报隐藏对象 FAIL 时保留并注明覆盖限制，不以浮空金块替代。可见路线、接口及支撑分别列 `声明/有限 PASS/未绑定/未知`，空路线/零 FAIL 不作全连接通过。工具不支持的曲面、遮挡、物理输运要留 UNVERIFIED；不要把记录中的对象原点/自写属性当真实界面。
- [ ] 实物接口任务逐跳核 `主体实作用面 → 插座/真实开孔 → 插头 → 缓冲 → 有截面外缆`，注射器核 `真实 barrel 端面 → 同轴 hub/nozzle → tube`；世界曲线最后整段取样核径向偏离、轴向与入座深度。检查局部到世界点/handle 只转换一次、父级/缩放，彩色游离端不得当遮挡或连接；细则见 [实物与接口方法](physical_equipment_and_interfaces.md)。针对当前域逐跳写清 `管线/线缆 → 接头或遮挡边界 → 所属器件`；分列机械固定、气动/液路或电连接。管端落在接头体积内仅为坐标证据，须另核可见孔口/归属/连通/密封来源；遮挡后未知就停，不加臆造接头。报告预期贴合、间隙、允许插入和不应穿入，不把零相交作为统一目标。
- [ ] 对本例有依据的镜面、孔板或扁带簧，按实网格法向、孔轴/拓扑、实体 z 厚度检查而不是信自写属性/对象数量；首次 FAIL 留档，不扩大阈值。地面/遮挡、near/far 有符号深度与 bbox 全角点水平/垂直投影**分开**检查；`key_parts_ok` 的 `in_clip_range` 只验轴向，不是完整入框。未独立做投影/遮挡就明列未覆盖；曲线须有渲染截面，PASS 数量不作图像验收。
- [ ] 局部视角如需隐藏遮挡件，先验证目标确实可渲染，渲染后（含异常）恢复；隐藏光学元件的局部图不证明完整光路。

## v1.1｜建模前强制四表/逐篇比图（旧 v1.0 原则的可执行前置）
- [ ] 写器件识别表（来源图/页/正文锚点、实际形态、支撑/装配、未知），逐例对照相似设备差异；笔电的屏/底座/键盘/转轴与台式 PC 区别、示波器显示面和信号端口区别，不能两个矩形替代；无型号不冒充厂商 CAD。详见 [前置门槛](identity_port_gate_v11.md)。
- [ ] 写逐个有证据端口/介质/owner 表和每根线两端的拓扑、遮挡及假设；不连屏幕、任意壳面或 bbox 中心。缺口则停对应路径/标未知，不用点重合宣称导通、密封、功能。
- [ ] 每篇记录来源 anchor、已保存 .blend/PNG 及 SHA、对应点与差异、几何分母/有限结论和**谁实际读了哪一版像素**；源图并排本地，高分辨率逐例核，不以缩略拼图顶替。[比图和演示方法](source_render_and_demo_v11.md)；保留旧失败/近景/无源前后版供分镜。

## 3｜实际渲染与参考图对照（P6、P19）
- [ ] 最终 `.blend` 另进程重开、显式更新依赖图后才出总览及同场景细节，记录 scene/PNG SHA 和相机；避免保存场景与构建进程 PNG 方向不一致。对照指定原图和**正确版本** PNG（每轮重建/修端点后更新哈希并重读），检查布局、轮廓、比例、整体装配、材料类别、接口/管路及构图；局部同时显示管端、接口、所属部件。实际记录各跳可见/遮挡/未知、机械与功能连接的不同确认等级，注明审查人/工具。
- [ ] 首选可直接读图能力；桌面截图失败且无进展时停止重试，核对文件/哈希后交外部读图，明确写“未视觉核查”。几何、色彩统计和材质节点数值不作视觉通过。
- [ ] 透明材质争议先冻结几何和相机，检实际渲染引擎支持的透射/Alpha、阴影、照明及采样，再比较 PNG 白雾/颗粒、孔壁和支撑可见性；总览不能为追细节裁主体，必要时另交局部。内面实网格存在仍可能被前层挡住；只有同几何补充视图可清晰显示时标补图隔离，不把补图结果冒充总览，且复原最终主相机/主物件渲染状态。案例参数不硬编码通用默认。

## 4｜阶段收口或正式图（P7、P12–P14、P20）
- [ ] 保留失败图/更正与版本后缀；针对修订项回查相邻关联件及**原来正确的整图范围**，清理旧版孤立残留或重复管线，保留未受影响的已认可项，不逐例重复重渲。渲染/截图/TRANSPORT 故障各自记录并从检查点恢复。
- [ ] 用户已接受阶段结果时可总结**经反馈支持的方法**并更新 Skill；未确认的隐藏接口继续留案例，不强求反复猜测。若用户要求正式图且读图达到约定标准，再做正式审查；没有正式图不得声称已交付。
- [ ] 记录真实 AGH 操作、确切版本、已验证范围、读图者（AGH／外部模型／用户）与待确认项；图注编号/材料冲突照录未知，拆解间隔/组装态不强迫假支撑或密封；项目记录可静态查缺项/错端口/介质，保存场景可分项查几何，PNG 辅助只报哈希/裁框；三种报告互不代替。外部阶段认可非用户最终验收，03–10 仍低成本。

**能力边界**：本包能提示身份/连接/来源/视觉分栏并提供静态/局部几何/图片数值辅助，不能自行验证厂家型号、隐藏连通、封装密封、受力/电/光学功能或任何项目的外部最终验收；案例证据归其验证工程，不随独立 Skill 分发。
