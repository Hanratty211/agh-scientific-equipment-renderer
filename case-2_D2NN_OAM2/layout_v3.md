## 二、修正 v2 的关键布局问题

### A. 参考图**不是"M1/M2/M3 各转 90°"**
- 参考图实际视觉组织：
  - **主水平光轴**在参考图 **y ≈ 400–450**（上半区，占主光路）
  - **下方折叠段**在参考图 **y ≈ 530–680**（探测器段：Holder/MMF/BC/PD/示波器）
  - **上方折叠段**在参考图 **y ≈ 65–170**（4f 系统 + dichroic 部分）
- **M1/M2 在参考图左侧（x 280–360）附近**，作用是把激光折向 DMD 斜入射面（入射角 12°）
- **M3 在参考图右侧（x 760–840 附近）**，把 SLM 出射光折向下方探测器段
- **不预设 M1/M2/M3 均 90° 转向**：
  - M1 实际入射 +x、出射斜向 DMD（12° 入射角）→ 法向在 45°+ 与 90° 之间
  - M2 实际入射斜、出射 +x 到 DMD 面 → 法向按入/出射线段算
  - M3 实际入射 +x（SLM 出射）、出射 -y 到下方探测段 → 法向 45°
  - **每个镜按实际入/出射线段求法向，不在 saved 场景验证反射方向之前锁定旋转**

### B. DMD 入射角 12°（更正 v2 约 45° 记录）
- **DMD 微镜阵列**入射角 **12°**（论文正文 / DMD 微镜标准微镜法），**不是 v2 假设的 45°**
- DMD 微镜衍射行为 ≠ 普通镜面反射（微镜阵列按衍射级出射，不按镜面反射定律）
- **不套用同一规则**：M1/M2/M3 普通镜按镜面反射定律；DMD 按微镜衍射（+1 级出射，经过 4f 滤波）
- DMD 面在参考图 x 440–480，**法向与 12° 入射光垂直**（微镜法面垂直于 12° 入射光）

### C. SLM 入射/返回/BS 分出（不从 SLM 背面继续画）
- **SLM 入射**：+x 方向（主光轴）
- **SLM 出射/返回**：SLM 相调制后出射光**仍沿 +x**（共光路，不折返）
- **BS(dichroic) 分出**：BS 按波长/偏振把零级（未调制）分出到 M3，**M3 再折 -y 到下方探测段**
- **不**从 SLM 背面继续画出射光（v2 误画）

### D. 消除 L6 前沿 +y / 后沿 +x 无依据转弯
- v2 把 L6 放在 (1.16, 0.60) 与 L7 放在 (1.30, 0.60) 之间，L6→L7 段沿 +x
- 但 v2 中 L5→L6 沿 +y（折叠段）、L6→L7 沿 +x（折回）——**这段无依据转弯不在参考图中**
- **修正**：L5/L6/L7 与 Holder 在参考图**同一水平（y ≈ 400–450 或下方探测器段 y ≈ 530–680）**，不新增转向镜
- 优先按参考图布局：L5/L6/L7 在主光轴水平段，L7 聚焦到 Holder（下方探测器段），**不新增转向镜**

### E. 透镜/光圈方向与局部光轴一致
- 每个透镜/光圈的**法向**与**局部光轴**一致（不斜放）
- Iris1/Iris2 必须有**真实通孔**（布尔开孔），法向与局部光轴一致

## 五、各光学件实际作用面/入射出射方向（修正）
- **L1/L2**：主光轴法向，入射 +x → 出射 +x
- **M1**：法向按入射（+x）与出射（斜向 DMD 12° 入射）路径定，**不预设 90°**；镜面法向 = (入射单位向量 + 出射单位向量) 归一
- **M2**：法向按入射（M1 出射斜向）与出射（DMD 面 12° 入射）路径定
- **DMD**：微镜阵列，法向垂直 12° 入射光（**微镜衍射**，+1 级出射经 4f 滤波，**不套镜面反射定律**）
- **L3/L4**：主光轴法向，4f 取 +1 级
- **BS(dichroic)**：主光轴法向，按波长/偏振分光
- **HWP/Polarizer**：主光轴法向薄片面
- **SLM**：主光轴法向，相调制（入射/出射 +x 共光路，**不折返**）
- **M3**：法向 45°（入射 +x 出射 -y），把 SLM 出射光折到下方探测段
- **L5/L6/L7**：下方探测段法向，第二组 4f + 聚焦
- **Iris1/Iris2**：**真实通孔**（布尔开孔），法向与局部光轴一致
- **Holder**：下方探测段焦面，三 MMF 并排固定
- **BC**：楔形/盒，三 MMF 输入 → 单 MMF 输出
- **输出 MMF/PD/示波器**：下方探测段末端，**PD→示波器用电信号线（深蓝细实线）**
