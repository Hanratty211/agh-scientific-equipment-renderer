# Case 3 · v04 仅修左侧白管下端的可见装配

## 依据和更正
参考：指定本地 `01_soft_robotics.jpg` 的弯管/主体中段，以及 Choe et al. [Fig. 3b、图注与对应正文](https://www.nature.com/articles/s41467-023-39691-z)。本轮实际通过 Preview 的 computer_use 观看参考局部、v04 总览及局部裁图。参考中弯管沿主体外侧绕至表盘**上方偏右**的配件/包覆交界，细小末端有遮挡；照片不足以辨识接口孔或指明属于调压器。论文正文仅说明 CO₂ 经机械调压向 STV 供气、STV 室压驱动两软指；不能用它把这条白管指定为表盘进气管。

v03 的 `left bend upper-side receiver` 是自行添加的孤立灰圆柱，不是参考确认的厂家接头，v04 **移除**。只在照片出现部件/包覆交界的位置用简化夹体与外侧压带表达「白管末端→可见夹体→主体外表面」的**视觉链**；白管终止于上侧深色凹面，不继续穿过主体或接入压力表。压带和两个暗色凹点是位置/外观代理，不代表经过证实的打孔、密封或气动三通。其余软指、主体、调压器、STV、手柄、右管、镜头和照明保持 v03，不补外围平台。

## 三种确认程度（不可互相替代）
- **视觉连接：有限，待外部确认。** 模型实际读 `detail_left_coupling_v04.png`：白管顺势进入灰色夹体上缘的深色位置；夹体左侧有短灰色带延伸至深色包覆的边缘，可同时看到白管、夹体、所属主体和下方未被接入的白色压力表。黑凹点细小、影像分辨率有限；其具体接口造型不是来源确定事实。
- **机械安装：示意，不作实物通过。** 场景里的夹体和压带为主体外侧相接的可编辑代理，避免 v03 短节单独漂浮，也未以管/节插入实心壳体作安装证据。参考只支持该处有可见装配交界，不显示背面固定、绑扎/粘接方式或负载路径；不能宣称夹体真实安装方式已核定。
- **气路身份：未确认。** 没有验证凹点存在贯通孔、气密性、该管是供气还是室压支路、隐藏路线或与压力表之间的管路。图中相邻不等于流体连通；这些继续标为未知。
