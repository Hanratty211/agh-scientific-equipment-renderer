# Case 3 · v02 外观及可见装配预览（待外部反馈）

## 依据与逐项改动
参考仍仅为指定 `01_soft_robotics.jpg` 与 [Choe et al., Nature Communications (2023), Fig. 3b、图注及相关正文](https://www.nature.com/articles/s41467-023-39691-z)。保留 v01 的 `build_scene.py`、`soft_gripper_v01.blend` 与 `overview_v01.png`；新脚本 `build_scene_v02.py` 不覆盖旧版。

1. **包覆主体**：单体纺锤形织物套向下收窄，两软指之间开口下凹，圆柔包边；不再做实心平顶盒。顶部开口只是可见轮廓，不表示已辨识内部截面。
2. **软执行器**：左右独立轮廓曲线、圆润末端、柔软连续芯和浅窄褶沟取代突出方块；两侧投影不强制镜像，也不声称左右真实长度不同。成像比 v01 柔和，但软指仍近似标准弧杆，段结构与照片的真实褶形未完全吻合。
3. **材料**：深灰布主体采用尺度细小的程序化微凹凸及高粗糙度，浅色硅胶指保留低金属、柔和表面；一条 v02 预览中呈悬空细线的装饰缝已在最终图删掉。这些均为展示参数，不是材料实测。
4. **前部附件**：仅建可见的罐端对比，不补内部 CO₂ 罐；压力表改为浅色圆盘、深浅双边框、无数字刻线及不表示读数的短指针。
5. **STV／手柄**：将 STV 置于下半段包覆前，圆角底端、贴近末端的灰色根部和照片启发的下方环状拉柄；未主张隐蔽固定方式。环仍略像管形拉环，不是厂家 CAD。
6. **管线**：左管在可见表面绕过表盘，到其上右侧的可见接收短节；右管沿外缘到下部 STV 上领。删掉 v01 里悬挂于下方的回形白管、没有依据的调压器→STV 明示蓝管；隐藏连接不再补出假接头。

## 有界核查与实际读图
- 运行 Blender 5.1.2 建模渲染，重新载入已保存 `.blend`：主相机为 `v02 no-text overview`，无 FONT；检查左、右可见软管末端的曲线控制点与脚本记录的终点完全相符。左终点 `(0.43,-0.52,-1.52)` 距示意短节中心 `(0.40,-0.52,-1.52)` 为 0.03 场景单位；右终点 `(0.37,-0.44,-2.39)` 距 STV 上领中心 `(0.33,-0.43,-2.40)` 约 0.042。两者位于对应接头圆柱的体积内，不是机壳中心或表盘中央。`case_role` 只是索引，**不以对象/控制点数量证明物理连接**。未核验隐藏气路拓扑、接头内部、材质配方或真实尺寸。
- 模型通过 macOS Preview 的 `computer_use capture(mode=vision)` **实际阅读**参考与 v01，并审阅 v02 总览和裁出的前部局部 PNG。总览仍可辨完整抓手，软指分段由方块改为浅褶，顶部有下凹包边，仪表可辨。局部图中白管端部靠近短节、另一端贴 STV 上领，未见终止在表盘旁的自由白管或从主体实心面穿出的白管；但短节体量较大，罩体过于光顺、STV 仍表现为前部短杆，底部灰色环形把手仍需外部判断。局部只是总览裁图，**不是独立视角或完整隐蔽连接证据**。模型目视也不能证明气路真实正确。
- 局部图从最终 `overview_v02.png` 原像素框 `(285,575,580,1010)` 裁切，2.4 倍放大，仅为读图，不加入文字；v02 不制作正式图。
