# v1.0 按需参考｜实物形态与完整可见接口

仅当任务涉及实体仪器外观、线缆/液管、穿壁口或已交付图的局部修复时读取。来源为公开材料与 [R1/R2/R3/R4 有界修复](evidence_index.md)；不把案例坐标、设备型号、尺寸、颜色或相机角度当默认。v1.0 是工作方法发布，不是工业 CAD/全领域验收。对每个可见链分列 `图/正文依据、公开型号依据、代表性假设、未知`，先锁完整装置与装配状态，再动局部。

## A. 先识别机器，再搭可辨实物

- 用来源图、图注、正文和（已知型号时）**可核的公开产品资料**确定类别、可见外壳/控制面、作用端、安装态。没有型号或资料时按任务需要画有明确假设记录的代表性外观/接口；无字图不强制加标注；不可发明厂家外壳、插头标准、额定性能。参考图若只示意遮挡段，不能自行闭合内部回路。
- 笔记本的屏幕、底座、转轴应机械连贯；按审图目的表现键盘/触控板、需要的侧/后数据口。数据线从底座实体端口出，不从显示面、屏幕边缘或实心外壳直接冒出。示波器显示/旋钮/输入环与电源、驱动泵、相机的控制面和接口布局要按**类别**区分；不以随意 2D 轮廓拉伸或通用方块代替关键仪器。未知控制面细节留为代表性而非型号对应。
- 注射泵的机架、真实注射器筒与杆、工作端须有相互关系；不能只画管子连到离体的尖嘴。浮空装饰环/彩色点、实心黑贴片不能代替真实孔腔或结构接口。开口需在真实壁/壳上形成带方向的可编辑孔壁，明确可见的空腔与所属物。

## B. 沿真实接口轴线逐跳完成外部连接

1. 列物理链：`主体实际后/侧/工作面 → 插座或开孔 → 入座插头/套筒 → 应力缓冲 → 有截面的连续外部线缆`；流体链为 `注射器真实 barrel 工作端面 → 同轴 hub/nozzle → tube`。记录每跳 owner、介质、暴露/遮挡/开放及来源；不把「路线端贴在 socket 中心」当插头已入座。带透明壁的可见游离彩色端属于待修复断口，不能用“可能被挡住”搪塞。
2. 用评估后的**实际网格**和 `matrix_world` 求工作面位置与世界法向；对含父级/旋转/非均匀缩放的局部点只转换一次，法向用适当逆转置并归一。按真实接口轴线与壁面的相交关系确定开孔轴线：正向口常沿壁面法向，但斜接口或斜入射窗口不得强制法向；在整个壁厚范围检查孔与线缆/光束包络的适配、孔内中空及附近壁完整，并分别检查插头/套筒跨口与缓冲搭接。接口角度无依据时明确记录建模假设，不当作来源事实。中心点落在**环形真实空洞**时，不能靠放大 `surface_tolerance` 将“中心贴面”伪装成 PASS；标 UNVERIFIED 并对环面/孔壁另作有限实体检查。
3. 外线始于或止于**缓冲件内部**（符合可见线径），沿缓冲尾端轴向伸出/插入；坐标用 `route.matrix_world @ bezier_point.co`，把左右 handles 也变换后采样**实际三次 Bezier 最后一整段**，报告入座深度、径向偏离、末端切向和壳体避让；只看最后点、对象原点、自写属性或包围盒重叠都不足以证明安装。平滑柔和而不强迫画完照片遮挡的路径，避免不合理过冲或穿屏/实心面。侧入、空气间隙、出界、旋转/父变换错误应作为能失败的反例；不为消除 FAIL 加大容差。
4. 改 owner 应表示完整所属主体或显式子组件，随后重查相关端口、两端 connection、required 范围、支撑、标签及历史审核；若外缆接在缓冲件而 socket 深藏于相机后壳，则静态路线为缓冲→另一外端，内部可见的座→插头→缓冲另核实网格，不能把外缆虚记为直接连接埋在机身里的 socket。未见的内部针头/集电极/气路/回流保持未知，不用虚构的隐藏线路补闭环。

## C. 修后独立保存、核图与证据等级

- 小范围改动先列可保留对象/路线，用精确对象标识处理，防止宽前缀删除顺带移除供液管。局部隐藏/替换遮挡件要在异常时也复原主相机、主件和渲染状态。源场景/失败图/失败报告保留新版本后缀；只改目标边界，再复核之前已通过的整图范围。
- 保存最终 `.blend`，在**独立进程**重开并显式更新 view layer / depsgraph，才生成最终 overview 与同场景细节。记录 scene SHA-256、每张 PNG SHA-256、使用的相机、实际版本；避免构建进程的旧依赖图让 PNG 与保存场景方向不一致。静态记录、有限实体几何、图像实际读图**分开**：重载/几何 PASS 不证明视觉连续、功能或电气安全。截图不可读即保留“未读图”，不要自称已审像素。
- 注明审阅作者：AGH 实际读图、外部模型独立读图、用户阶段认可均不可互相代写。外部阶段预览或用户代表性低成本预览收口，不等于人类最终验收、厂家 CAD、制造公差、密封、电气/高压安全、内部连通或跨域泛化。若范围完成且用户要求停，可不再渲染。

**工具边界**：现有 `agh-equipment/0.6` JSON schema 与已用 API 保持不变；`validate_project_record.py` / `audit_saved_scene.py` 给静态/部分已声明对象的有限结果，不会自动验证整条实物接口链。可按当前问题做独立局部实网格/曲线探针；别将新探针描述为旧 API 已覆盖。参见 [项目记录](project_record.md)、[工作清单](workflow_checklist.md)及[故障经验](pitfalls_and_fixes.md)。
