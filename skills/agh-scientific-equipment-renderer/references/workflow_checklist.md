# v0.3 工作清单｜按任务选用，不设固定视角或采样数

参见 [故障经验 P1–P20](pitfalls_and_fixes.md)；每项只对**当前用户目标和可获得证据**成立。主要产物是实物三维示意场景和参考图可对照的低成本预览，不把标签副本或二维草图设为必经步骤。

## 0｜理解来源（P11、P15）
- [ ] 确定用户指定图版/子图、图注、相关正文/方法；记录“已实现／拟建／未定”。
- [ ] 建立器件/传输路径/作用面清单：逐件区分 `原图可见 / 正文依据 / 建模假设 / 未定`；图注与正文命名差异并列，不消解。
- [ ] 在身份有争议时才做标注副本或 2D 草图，并用图中标签、正文、必要型号来源交叉核对。图上红色光束、Hologram/Phase 插图等先判断是否示意，不凭常见结构补实体。

## 1｜最快低成本整体 3D（P1、P16、P17）
- [ ] 先搭完整布局/可识别外形和传播、光纤/探测器连接；选成本合适的总体预览，早交用户/外部对照原图。相机位置、分辨率、采样、视角数按任务设置。
- [ ] 直通段共用光轴；镜面折转按来源与实际面法向；中心线与扩束/准直/聚焦包络分开。源、光纤、探测接口取真实面；避免“中心共线但源端埋在壳体内”。
- [ ] 物体形状与安装细节若论文未给，只作显式示意假设；不要套两个光学案例的型号/尺寸/颜色/材质/相机。

## 2｜有界的独立核查（P2–P5、P8–P10、P18–P19）
- [ ] 独立载入**已保存** .blend，用真实工作面/法向、当前世界变换和正确单位核查关键传播与连接；避免 bbox 面代理和对象自定义 normal 自证。
- [ ] 报告预期贴合、间隙、允许插入、不应穿入与先碰到的真实阻挡；只排除当前示意束自命中，不将“全部接触=0相交”强制套用。
- [ ] 地面/遮挡、相机有符号深度与全角点横纵投影分别检查；曲线须有实际可渲染截面。明列检查覆盖与未覆盖，PASS 数量不作图像验收。
- [ ] 局部视角如需隐藏遮挡件，先验证目标确实可渲染，渲染后（含异常）恢复；隐藏光学元件的局部图不证明完整光路。

## 3｜实际渲染与参考图对照（P6、P19）
- [ ] 对照指定原图和**正确版本** PNG，检查布局、轮廓、形态、比例、作用面、束宽、镜片/接口辨识、相机/桌面构图；记录审查人/工具和实际观察。
- [ ] 首选可直接读图能力；桌面截图失败且无进展时停止重试，核对文件/哈希后交外部读图，明确写“未视觉核查”。几何、色彩统计和材质节点数值不作视觉通过。
- [ ] 材质争议先冻结几何/相机/照明，做低成本局部候选图，待外部选择再应用整体；不要以“透明越多越好”或显示红色当作光波长事实。

## 4｜阶段收口或正式图（P7、P12–P14、P20）
- [ ] 保留失败图/更正与版本后缀；对渲染失败、截图失败、TRANSPORT 中断各自记录与从检查点恢复，不能混写。
- [ ] 用户已接受阶段结果时可总结方法并更新 Skill；若用户要求正式图且核查/实际读图达到约定标准，再做所需分辨率、视角和正式审查记录。没有正式图不得声称已交付。
- [ ] 记录真实 AGH 操作、输出哈希、已验证范围、外部/模型读图方式与待确认项；两个公开光学案例不证明全领域适用。
