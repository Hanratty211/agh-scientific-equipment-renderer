# v0.6 工作清单｜按任务选用，不设固定视角或采样数

参见 [故障经验 P1–P28](pitfalls_and_fixes.md)及 [按需域检查](domain_checks.md)；每项只对**当前用户目标和可获得证据**成立。需要机器核查时使用 [可选项目记录](project_record.md)，不把它变成普通预览的必填大表。主要产物是实物三维示意场景和参考图可对照的低成本预览，不把标签副本或二维草图设为必经步骤。

## 0｜理解来源（P11、P15）
- [ ] 确定用户指定图版/子图、图注、相关正文/方法；记录“已实现／拟建／未定”。批次拼图先核子图范围：裁出装置而不混数据图，保留图号和必要标签；裁图本身也需实际读图复核。
- [ ] 建立器件/传输路径/作用面清单：逐件区分 `原图可见 / 正文依据 / 建模假设 / 未定`；图注与正文命名差异并列，不消解。材料类别/名称先查正文和方法，照片外观纹理另列为估计。
- [ ] 在身份有争议时才做标注副本或 2D 草图，并用图中标签、正文、必要型号来源交叉核对。图上红色光束、Hologram/Phase 插图等先判断是否示意，不凭常见结构补实体。

## 1｜最快低成本整体 3D（P1、P16、P17）
- [ ] 先搭正确子图的**整套装配范围**、朝向、层次、相对比例和主要接口；选低成本总览尽早外部读图。照片上的箭头/标框先分离，未证实的硬件不补画。相机/采样按任务设置，不把二维图片 y 当实际高度。
- [ ] 直通段共用光轴；镜面折转按来源与实际面法向；中心线与扩束/准直/聚焦包络分开。源、光纤、探测接口取真实面；避免“中心共线但源端埋在壳体内”。
- [ ] 先对照整体轮廓、连续结构、相对比例与材料类别；功能性孔腔/入口用实几何，不以表面暗点代替。柔性分段按可见轮廓而非方块/纹理噪声；圆片/环面与图形标记各自核身份。安装细节若论文未给只作显式假设，不套旧案例参数。

## 2｜有界的独立核查（P2–P5、P8–P10、P18–P19）
- [ ] 独立载入**已保存** .blend；用实际评估后网格/世界变换核接口 owner 表面、所支持的曲线/直束端点与有限接触（显式容差）。工具不支持的曲面、遮挡、物理输运要留 UNVERIFIED；不要把记录中的对象原点/自写属性当真实界面。
- [ ] 针对当前域逐跳写清 `管线/线缆 → 接头或遮挡边界 → 所属器件`；分列机械固定、气动/液路或电连接。管端落在接头体积内仅为坐标证据，须另核可见孔口/归属/连通/密封来源；遮挡后未知就停，不加臆造接头。报告预期贴合、间隙、允许插入和不应穿入，不把零相交作为统一目标。
- [ ] 地面/遮挡、near/far 有符号深度与 bbox 全角点水平/垂直投影**分开**检查；`key_parts_ok` 的 `in_clip_range` 只验轴向，不是完整入框。未独立做投影/遮挡就明列未覆盖；曲线须有渲染截面，PASS 数量不作图像验收。
- [ ] 局部视角如需隐藏遮挡件，先验证目标确实可渲染，渲染后（含异常）恢复；隐藏光学元件的局部图不证明完整光路。

## 3｜实际渲染与参考图对照（P6、P19）
- [ ] 对照指定原图和**正确版本** PNG，检查布局、轮廓、比例、整体装配、材料类别、接口/管路及构图；局部同时显示管端、接口、所属部件。实际记录各跳可见/遮挡/未知、机械与功能连接的不同确认等级，注明审查人/工具。
- [ ] 首选可直接读图能力；桌面截图失败且无进展时停止重试，核对文件/哈希后交外部读图，明确写“未视觉核查”。几何、色彩统计和材质节点数值不作视觉通过。
- [ ] 透明材质争议先冻结几何和相机，检实际渲染引擎支持的透射/Alpha、阴影、照明及采样，再比较 PNG 白雾/颗粒、孔壁和支撑可见性；总览不能为追细节裁主体，必要时另交局部。案例参数不硬编码通用默认。

## 4｜阶段收口或正式图（P7、P12–P14、P20）
- [ ] 保留失败图/更正与版本后缀；针对修订项回查相邻关联件，清理旧版孤立残留或重复管线，保留未受影响的已认可项，不逐例重复重渲。渲染/截图/TRANSPORT 故障各自记录并从检查点恢复。
- [ ] 用户已接受阶段结果时可总结**经反馈支持的方法**并更新 Skill；未确认的隐藏接口继续留案例，不强求反复猜测。若用户要求正式图且读图达到约定标准，再做正式审查；没有正式图不得声称已交付。
- [ ] 记录真实 AGH 操作、确切版本、已验证范围、读图者（AGH／外部模型／用户）与待确认项；项目记录可静态查缺项/错端口/介质，保存场景可分项查几何，PNG 辅助只报哈希/裁框；三种报告互不代替。外部阶段认可非用户最终验收，03–10 仍低成本。

**当前经验状态**：case-1 有正式图；case-2 低成本总览，无正式图；case-3 软体抓手 v05 获用户阶段认可但气路仍未知；03–10 获外部模型有限读图反馈，非用户最终验收。07 只证范围改善，功能拓扑未验证。证据与撤回见 [证据索引](evidence_index.md)。
