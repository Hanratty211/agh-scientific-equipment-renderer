# 科研装置三维渲染｜v1.0

**主目标**：依据指定图版、图注和正文先制作**完整、可编辑的实物三维低成本总览**，再以实际像素迭代。器件类别/可见结构与有据型号决定实物形态；未知品牌外观只作代表性示意。可见接口逐跳验证真实部件作用面、可编辑开孔、插头、缓冲及曲线世界端点/末段切向，不以代理锚点、对象原点、属性或颜色圆头自证连接。详见按需[实物与接口方法](references/physical_equipment_and_interfaces.md)。六例 R1–R4 修复得到代表性低成本预览阶段反馈，但不证明厂家 CAD、内部连通、制造/电气安全、密封或泛化。

## 工作方式
1. **先定来源与范围**：读目标图版、图注、必要正文/方法（不清楚则查较高清公开图与有关补充材料）；**先按源图/图注/用户范围建立必需组件与关系清单，再建对象**，列身份、形态、连续路径、装配/拆解状态、作用面与未知项；通用仪器方块不能替代源图的笔电、显微镜、注射驱动或有纹理的多层单元。逐条区分 `来源可见 / 正文依据 / 建模假设 / 未定`；材料名称先核正文，纹理、色彩与照片观感不替代来源事实。原图的示意色/插图不当作实物或实测光束颜色；命名差异并列记录。
2. **快速建低成本整体 3D**：先锁定指定子图的完整装配范围、朝向、部件所属关系与相对比例，再刻细节；不能把整套测试装置缩为孤立器件。可见孔腔/入口须用真实可编辑几何，不以暗色圆点冒充；图上箭头/标框与实物分开。照片可辨的柔性分段按连续轮廓建模，不以通用方块或噪声代替。参考标注或 2D 草图仅识别困难时按需做；图面坐标不直接当世界坐标。
3. **针对关系核查**：逐跳核对连接的两端与所属主体 `管线/弹簧/束 → 接头或遮挡边界 → 所属部件`，分辨机械、流体、电与光学连接；以当前场景单位记录可见且有来源的接口/路线分母、已绑定与未知/未绑定关系、支撑覆盖；0 条路线/零 FAIL 非线路验证，不为过审发明接口或缩小必需范围。局部锚点经 owner 的实际 world matrix **恰变换一次**再核真实作用面；QA 锚点应贴真实面，可作非渲染几何证据（若现有审计误报隐藏渲染，应留 FAIL/未覆盖，不为过审改成浮空金块）；不把浮空金块当硬件。端点贴近不证明关节/受力或回流拓扑。照片仅见分段时停在可辨接口/遮挡，不自行闭合管路。最终场景保存后另进程重开并更新依赖图，按任务检查作用面、轴线、曲线世界端点及末段采样切向，记录场景与 PNG 哈希；针对当前目标核真实镜面法向/折转、孔的法向与拓扑、平面带簧而非螺旋；自写属性/对象数量不代替实网格。轴向 near/far 与横纵投影分别报告，遮挡未查就标未覆盖；不放大容差掩盖 FAIL。批量修订只动受影响项及关联残留，避免重复件和无来源旧附件；PASS 不等于视觉或功能验收。
4. **实际读图再改**：参考图与 PNG 对照整体范围、比例、可见连接、材料、孔壁及构图；总览须保留指定整图范围、装配相对位置与留边；内面存在于网格却被前层挡住时可另交**同一几何**的隔离细节，恢复主镜头和全部主件渲染状态，明确细节不等于总览可见。透明外观按**所用引擎**选择透射/Alpha、照明和低成本采样，实际读 PNG 排查白雾/颗粒；参数只作案例候选，不设通用值。批量交付可用参考–前版–最新版拼图，裁选定子图须同时排除无关数据图并保留必要标签。记确切版本与读图者（AGH 本人／外部模型／用户／未完成），区分论文依据、建模假设、自动核查和像素判断；截图无进展时交图外审，不以文件/数值冒充视觉通过。
5. **按任务收口**：独立案例可按批交付脚本/场景/PNG/检查点；失败从已落盘版本续做，不重建通过部分；针对目标特征的局部修复须再次核原本正确的完整范围，不以局部射线 PASS 覆盖全图回退。用户接受阶段成果后才可称用户阶段认可；外部模型读图认可只作有限反馈，不升格用户最终验收。只在需求和约定读图允许时做正式图；保留失败版本、正确裁图、未知项与真实 AGH 索引，区分截图/渲染/TRANSPORT 故障。

## 可选轻量工具（不阻塞普通预览）
- 首轮仍先搭完整低成本 3D；当需要记录/核查时，复制 [`examples/valid_record.json`](examples/valid_record.json)，按 [项目记录字段](references/project_record.md) 保留用户原始范围、必需组件/连接、接口 owner、介质与开放未知。`python3 scripts/validate_project_record.py record.json --report record_report.json`：空范围为 UNKNOWN，错引用/媒介为 FAIL；声明的 required 必须源于原始范围而非已建对象，不要缩小范围来凑 PASS。
- 从磁盘重开最终场景核查：`blender --background scene.blend --python scripts/audit_saved_scene.py -- record.json --report audit.json`；只检查已声明几何的对象/端点/支撑**顶点采样近接**、轴向裁剪、横纵投影；未采到支撑近接为 UNVERIFIED，不能否定完整面接触；端口/连接缺显式容差则对应项 UNVERIFIED（Blender 场景世界单位）。record 静态 FAIL 时停止几何审核；render 只识别部分明确排除且不把 hide_viewport 当渲染失败，不能声称像素可见；遮挡、物理功能及图片可读性均 UNVERIFIED。对象身份、端口 owner 变化后根据报告依赖关系重查路径、标签和旧 QA。小反例命令见 [项目记录](references/project_record.md)。
- 图片数值辅助：`python3 scripts/review_images.py review_config.json --report review.json`，归一化裁图与拼图保留原图哈希/像素范围；**数值不证明清晰或拓扑**。仅当用户需要有字混合图，用 `blender --background scene.blend --python scripts/make_svg_labels.py -- record.json labels.svg` 得到目标网格投影锚定的可编辑水平文字/引线。无字任务禁止调用标签生成；文字本身边界未测，长文字须目视检查，不能把锚点入框当文字完整；不重渲旧案例。

## 适用边界与按需参考
- 适用于来源清楚的科研装置**示意性三维重建**；不保证精密工程 CAD、真实尺寸、厂家外壳一致或任何领域一键复刻。具体光学型号、透镜曲率、角度、材质配方、采样数、视角数、相机与容差均由**当前任务证据**决定，不设案例默认。
- [实物与接口方法](references/physical_equipment_and_interfaces.md)供物理外观/线缆/孔口任务按需读取；[工作清单](references/workflow_checklist.md)：按需勾选；[故障经验](references/pitfalls_and_fixes.md)：触发—行动—证据—边界；[按需域检查](references/domain_checks.md)与[项目记录](references/project_record.md)；[证据索引](references/evidence_index.md)及[11–20 公开批次](references/public_validation_11_20.md)：批次简表在 Skill 内自包含，旧案例开发仓库链接是可选档案（拷贝 Skill 后缺少它们不影响工具）；[出处与版本](PROVENANCE.md)：AGH 轨迹及限制。
- `scripts/blender_core.py` 为已有可复用几何助手，**不要求每个案例都调用**；`scripts/check_structure.py` 做结构/frontmatter/引用与已有反例行为核查。其通过不是跨领域或视觉验收。
