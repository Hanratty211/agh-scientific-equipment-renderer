# 科研装置三维渲染｜v0.3 试用版

**主目标**：依据用户指定图版、图注及相关正文，尽快制作**可编辑的实物三维装置低成本总览**，再根据实际渲染与参考图的对照迭代。既不把示意连接冒充厂家 CAD，也不把两例光学经验当成所有科研装置的通用默认。case-1 有正式图；case-2 已迭代低成本预览、用户允许沉淀 Skill，**没有正式图**，材质候选对比**尚未应用到总览**。

## 工作方式
1. **先定来源与范围**：读目标图版、图注、必要正文/方法；列器件身份、传播/连接顺序、作用面、实现状态、可见结构和未知项。逐条区分 `来源可见 / 正文依据 / 建模假设 / 未定`；原图的示意色/插图不当作实物或实测光束颜色。命名不同时并列记录，别替来源消除差异。
2. **快速建低成本整体 3D**：先锁定总体布局、器件体量及连续连接，再改细部。参考图标注副本、二维草图**仅在识别困难时按需使用**，不是必经门槛。相机、器件、光束包络分别配置；勿把图面 y 当物理高度，勿把独立估计的像素点机械连成光轴。
3. **针对关系核查**：直通段共用轴，有来源的镜面折转按最终网格作用面核对；源端、光纤端、探测端贴真实接口。区分中心线与扩束/准直/聚焦的宽度表达。用带单位与容差的表面求交、障碍、自身示意光束排除、入框全角点检查；对已保存场景独立复算。连接可有设计所需的贴合或插入，**不以所有实体相交为零**作统一标准。PASS 数量只说明检查覆盖的条件。
4. **实际读图再改**：低成本 PNG 与指定参考图逐一对照布局、外形、比例、束形、材质、构图；记录确切版本和读图者（模型直接读图／用户或外部实际读图／未完成）。文件存在、材质参数、颜色统计及几何 PASS 均不等于视觉通过。材质不确定时固定几何、照明和相机做小样对比；光束以表达清楚且器件可辨为目标，不强制高透明比例。优先用环境可用的直接图像读取；桌面截图服务失败时停止无进展重试，交出正确文件供外部读图。
5. **按任务收口**：用户接受阶段成果即可更新 Skill，不以正式渲染或全领域验证为每轮前提。仅在任务需要且局部/总览读图通过后做正式图；保留失败版本、更正与真实 AGH 执行轨迹。区分截图失败、生成/渲染失败与模型 TRANSPORT 中断；从已落盘检查点续做，不虚报完成。

## 适用边界与按需参考
- 适用于来源清楚的科研装置**示意性三维重建**；不保证精密工程 CAD、真实尺寸、厂家外壳一致或任何领域一键复刻。具体光学型号、透镜曲率、角度、材质配方、采样数、视角数、相机与容差均由**当前任务证据**决定，不设案例默认。
- [工作清单](references/workflow_checklist.md)：按需勾选；[故障经验](references/pitfalls_and_fixes.md)：触发—行动—证据—边界；[证据索引](references/evidence_index.md)：两案例文件与撤回链；[出处与版本](PROVENANCE.md)：AGH 轨迹及限制。
- `scripts/blender_core.py` 为已有可复用几何助手，**不要求每个案例都调用**；`scripts/check_structure.py` 做结构/frontmatter/引用与已有反例行为核查。其通过不是跨领域或视觉验收。
