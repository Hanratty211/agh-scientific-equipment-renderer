# 同一 Agnes 模型：纯提示词与调用 Skill 的图片对照

两组均使用 Agnes / gpt-6-sol、同一模型路由与 standard 配置、相同来源图和基础任务，从空场景开始。纯提示词组实际读取 Skill **0 次**；Skill 组实际读取 v1.1.1 **1 次**。候选设计由各自 Agnes 会话生成，AI 助手没有替两组修改候选模型。

## 人工核查结论（主要验收依据）

用户对同一对图片进行已知分组判断：

|人工判断维度|结果|
|---|---|
|器件与完整性|Skill 更好|
|连接与接口|Skill 更好|
|支撑与装配|相当|
|外形与比例|Skill 更好|
|清晰度与构图|相当|
|整体更愿意使用|Skill 更好|

本次人工核查为主要验收依据：四项更好、两项相当。评审人数为1，图片配对为1；这是本次用户偏好，未换算为数值分数，不推断独立盲评、统计显著性或普遍优势。[完整人工验收](../HUMAN_REVIEW.md) · [结构化结果](../human-acceptance.json)。

## 执行与复核条件

每组预算为初建 900 秒、原生图片反馈 300 秒，最多一次视觉修改。两组最终均为 Cycles CPU、64 samples、seed 7、denoise、1800×1280；模型采样种子未受控。独立重开最终场景渲染，均与交付 PNG 的解码 RGB 像素完全一致。

执行中存在权限适配及路径错误：首次基线未产图，后以相同输入在新会话重试；Skill 组在同会话恢复自身提出的修复，扣除已用初建时间。实际完成顺序为 Skill → 基线重试，故不据此比较速度或 token 效率。原失败、预算与干预记录完整留在本地。
